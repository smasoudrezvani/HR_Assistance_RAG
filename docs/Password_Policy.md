# Password Policy
**Call360 | Version 1.1 | Effective January 2026**

## Purpose

Strong password practices are one of the most effective defenses against unauthorized access to Call360 systems and data. This policy sets minimum password standards for all employees.

## Password Requirements

All passwords used for Call360 systems must meet the following standards:

| Requirement | Standard |
|---|---|
| Minimum length | 14 characters |
| Complexity | Mix of uppercase, lowercase, numbers, and special characters |
| Uniqueness | Unique per service — never reuse passwords across accounts |
| Sharing | Never shared with anyone — including IT staff |
| Storage | Stored only in 1Password (company-issued account) |

## Multi-Factor Authentication (MFA)

MFA is **mandatory** for:
- Microsoft 365 (email, Teams, SharePoint)
- PeopleBase (HRIS)
- Jira and Confluence
- All cloud services handling sensitive data
- VPN access

MFA must not be disabled without IT approval.

## Password Manager (1Password)

Call360 provides every employee with a licensed 1Password account. All work-related passwords must be stored in 1Password. Benefits:
- Generates strong, unique passwords automatically
- Stores credentials securely and encrypted
- Enables secure sharing of team credentials via shared vaults

Setup instructions are available in Confluence → IT → Getting Started → 1Password.

## Shared Accounts and Shared Vaults

Some tools require shared team credentials (e.g., social media accounts, shared API keys). These must:
- Be stored in the appropriate 1Password shared vault
- Never be emailed or posted in Slack
- Be rotated whenever a team member with access leaves Call360

Contact IT if you need a shared vault created.

## Password Reset

If you believe your account has been compromised:
1. Change your password immediately via the relevant system
2. Notify IT at security@call360.com
3. Change your master 1Password password if you suspect that was compromised

## When Employees Leave

IT rotates all shared vault passwords when an employee who had access leaves Call360. Employees should not retain access to any Call360 systems after their last working day.
