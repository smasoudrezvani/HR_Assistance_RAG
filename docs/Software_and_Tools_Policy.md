# Software and Tools Policy
**Call360 | Version 1.2 | Effective January 2026**

## Purpose

This policy governs how employees select, use, and manage software and digital tools at Call360. It ensures security, cost control, and operational consistency.

## Approved Tools

Call360 maintains a curated list of approved tools available in the internal Confluence under **IT → Approved Software**. These have been vetted by IT and Information Security. Examples include:

| Category | Tool |
|---|---|
| Communication | Slack, Microsoft Teams |
| Email & Calendar | Microsoft Outlook / Microsoft 365 |
| Project Management | Jira, Asana |
| Documentation | Confluence, SharePoint |
| Design | Figma |
| Data & Analytics | Tableau, Metabase |
| Password Management | 1Password (company account) |
| HR System | PeopleBase |
| AI Assistants | Approved AI tools list (see AI Tools Usage Policy) |

## Requesting New Tools

If you need a tool not on the approved list:

1. Check the approved list in Confluence first
2. If not listed, complete the **Software Request Form** in PeopleBase
3. IT will review for security compliance
4. Finance will review for budget impact
5. You will receive a decision within 5 business days

Do not sign up for paid SaaS tools using a company card without prior approval.

## Personal Software on Company Devices

- Lightweight personal apps (music, productivity) are permitted provided they do not impact performance or security
- No pirated or unlicensed software is permitted under any circumstances
- Software that requires elevated or admin-level access must be approved by IT

## Browser Extensions

Browser extensions must be reviewed and approved by IT before installation on company devices. Common approved extensions (e.g., 1Password, Grammarly) are pre-listed. Unapproved extensions — especially those requesting access to all websites — are a security risk.

## SaaS Subscription Management

Finance and IT maintain an inventory of all company SaaS subscriptions. Employees should not create duplicate subscriptions for tools already licensed at company level. Unused personal subscriptions funded by the company should be reported to IT for cancellation.

## License Compliance

Call360 is committed to using all software in compliance with vendor licensing terms. Never copy, share, or distribute software in violation of its license agreement.
